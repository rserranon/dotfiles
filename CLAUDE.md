### Stow Layout Rule

Every stow package uses **double-nesting**: `<pkg>/<pkg>/` → `~/.config/<pkg>/`.
Example: `nvim/nvim/init.lua` → `~/.config/nvim/init.lua`

**Packages managed by `install.sh` stow loop:**
`alacritty  aliases  git  homebrew  nvim  starship  tmux  zsh`

Note: `claude`, `copilot`, `osx` are **not** in the stow loop — handled with explicit `ln -sf` calls.

**Special symlinks** (outside `~/.config`):

| Source | Target | Notes |
|--------|--------|-------|
| `zsh/.zshrc` | `~/.zshrc` sources it | macOS reads `~/.zshrc` directly |
| `claude/CLAUDE.md` | `~/.claude/CLAUDE.md` | global Claude Code context |
| `claude/settings.json` | `~/.claude/settings.json` | Claude Code permissions |

## Conventions

### Commit Style

Conventional Commits enforced. Format: `type: lowercase imperative subject` (no period, ≤72 chars).

Types used in this repo:
  - **feat**: 11 commits
  - **fix**: 5 commits
  - **docs**: 3 commits
  - **chore**: 2 commits
  - **test**: 1 commits

**Examples from history:**
- `feat: add Claude Code CLI integration`
- `fix: remove starship init guard that breaks tmux session restore`
- `chore: dotfiles health check fixes`
- `docs: update README and CLAUDE.md to reflect current state`
- `test: add dotfiles test suite with make test-dotfiles`

### Code Patterns

- **Lua plugins**: return a single table; use `opts =` (not `config =`) when possible; declare keybinds in `keys =`
- **Shell scripts**: `set -euo pipefail`; colored output via `pass()`/`fail()`/`warn()` functions
- **Aliases**: grouped by domain with `# comment` headers; no spaces around `=`
- **Stow packages**: double-nested (`pkg/pkg/file`); never put files directly at package root
- **JSON**: ignored globally (`*.json`) with `!claude/**/*.json` exception for Claude configs
- **Secrets**: always guarded with `[[ -f path ]] && source path`; never committed

## Secrets & Sensitive Config

`~/.config/secrets` is sourced by `.zshrc` and is **not in the repo**. Create manually on new machines:

```bash
# ~/.config/secrets
export ANTHROPIC_API_KEY="sk-ant-..."
export AWS_PROFILE="default"
export AWS_REGION="us-east-1"
# add other API keys, tokens, etc.
```
